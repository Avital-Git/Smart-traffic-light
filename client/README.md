# Smart Traffic Website

ממשק React לניהול פרויקט התנועה החכמה.

## מה יש כאן כרגע

- בחירת צומת ספציפית
- מצב תנועה בזמן אמת
- מצב רמזורים בזמן אמת
- גרף עומסים
- שליטה ידנית דרך האתר
- התרעות חירום

## הרצה

```bash
cd client
npm install
npm start
```

האפליקציה תנסה להתחבר לשרת FastAPI, ואם endpoint מסוים עוד לא קיים היא תעבוד עם fallback/mock data.
